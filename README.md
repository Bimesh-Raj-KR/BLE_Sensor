# G_Test

A project to **port** a struct into another struct of different type elements and then testing the **functions** involved using **Google Test**

## Features

Test and validate the output of the function **portStruct**   
The following Tests are done   

1. Null check  
2. Data verification check  
3. Data overflow check  
4. Negative value handling check  
4. Data rounding check  

## Building with Make

### make run

Output: run (runnable binary)

### make test

Output: test (Google test binary)

### make clean

removes run  
removes test
