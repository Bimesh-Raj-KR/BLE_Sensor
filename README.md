# G Streamer

A C project to send a file from a **sender** to **receiver** using **GStreamer pipelines** through **UDP_RTP**

## Prerequisites

The code is configured to handle **audio** files
Start **receiver** before running the **sender**

## Features

Every new send to the running receiver will append the received file

## Building with Make

### make send

Output: send

#### make receive

Output: receive
