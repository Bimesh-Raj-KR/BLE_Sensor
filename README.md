# List Files

A cross-platform C project that list files opened by a remote device and allows categorization of the list on the basis of open files or PIDs

## Features

List all running processes and Opened files in **fileOpenList.txt**

## Prerequisites

**Make**

**aarch64-linux-gnu-gcc** (for remote device build)

## Building with Make

### $ make List

Output: appList

## Requirements

Run **appList** on the remote device were you want the list
